# AO Quill plugin

Network-activated WordPress plugin. See `docs/setup.md` for installation and `docs/architecture.md` for the abilities it exposes.

## Layout

| Path | Purpose |
|---|---|
| `ao-quill.php` | Plugin header and bootstrap |
| `includes/class-aoq-abilities.php` | Ability registration with schemas from `contracts/` |
| `includes/class-aoq-runs.php` | Claim with lease, stage log, finish |
| `includes/class-aoq-commit.php` | `commit-post` with rollback |
| `includes/class-aoq-media.php` | Image download, validation, cross-site copy, license meta |
| `includes/class-aoq-marking.php` | Private AI marking |
| `includes/class-aoq-inventory.php` | Inventory across language sites |
| `includes/adapters/` | Multilingual and SEO adapters |
| `includes/admin/` | Settings, run log, status screens |
| `contracts/` | Generated by `scripts/build_contracts.py`; do not edit |
| `capabilities.json` | Capability status shown in the status panel |

## Tests

The tests use the WordPress multisite test suite and run in Docker:

```bash
docker compose -f wordpress-plugin/tests-docker/docker-compose.yml run --rm phpunit
```

`WP_VERSION` selects the WordPress release (default 7.1.3). Syntax check only: `wordpress-plugin/bin/lint.sh`.
